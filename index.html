Обо мне

Это учебный сайт по практической работе «Поиск бесплатного хостинга и размещение вебсайта». Работу выполнил студент antonkad2010-cpu.

Цель работы

Цель работы в том, чтобы найти бесплатный хостинг для статического сайта, разместить на нём свою страницу и сделать её доступной в интернете по постоянной ссылке.

Ход работы

В качестве хостинга выбран GitHub Pages. Для сайта создан публичный репозиторий practical-work-website, в него загружен файл index.html.

Затем в настройках репозитория включена публикация GitHub Pages с ветки main из корневой папки. Через пару минут сайт стал доступен по адресу antonkad2010-cpu.github.io/practical-work-website.

Стили страницы написаны прямо в HTML-файле: тёмная тема, анимированный градиентный фон, яркие акценты и подпись автора.

Вывод

GitHub Pages хорошо подходит для учебных и личных сайтов: он бесплатный, быстро настраивается и сам обновляет сайт после каждого коммита. Ограничение в том, что он размещает только статические сайты, без серверного кода.
